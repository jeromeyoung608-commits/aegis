DSAR request ledger (GDPR Art. 15 / 12)

Record data-subject requests and track the one-month (30-day) statutory deadline. Overdue rows are flagged. Resolving records the operator note and the completion time.

DPIA trigger check (GDPR Art. 35)

Advisory check based on the Controller's own dpia flags (set via the compliance facts JSON / API). Does not replace counsel's judgement.

Data subject access (DSAR / Art.20)

Export a self-describing JSON bundle of audit records + operator metadata a data subject can retrieve (GDPR Art.20 portability). Contains no key material or file bytes.

Erasure request (Art.17)

Erase a data-subject's personal references. Operator/system audit trail is protected and cannot be erased (B-04). Returns a salted tombstone hash so you can later prove the erasure without storing clear-text.
