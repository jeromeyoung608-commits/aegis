# Rechtliche Dokumente — Übersicht und Rangfolge

| Dokument | Zweck | Verbindlich? |
|---|---|---|
| `LICENSE` (Apache-2.0) | Lizenz für die Software | Ja, für die Softwarenutzung |
| `NOTICE` | Fremdkomponenten und ihre Lizenzen | Ja, zwingende Namensnennung |
| `docs/legal/ORDER-FORM-TEMPLATE.md` | Kommerzielle Bedingungen einer Beauftragung | Ja, nach Unterzeichnung |
| `COMMERCIAL-LICENSE.md` | Bedingungen für Support und Dienstleistungen | Ja, sobald im Bestellformular referenziert |
| `PRICING.md` | Listenpreise und Tarifbeschreibungen | Nein (informativ) |
| `TRADEMARK.md` | Regeln zur Nutzung von Name und Marke | Ja, als Rechtehinweis |
| `SECURITY.md` | Richtlinie zur Schwachstellenmeldung | Richtlinie, kein Vertrag |
| `docs/legal/DPA-STATEMENT.md` | Datenverarbeitung und kurze ADV | Ja, wenn Support-Zugriff gewährt wird |
| `docs/SERVICES-AGREEMENT.md` | Vollständige Dienstleistungsvereinbarung hinter dem Bestellformular | Ja, nach Unterzeichnung |
| `docs/DEPLOYMENT-DELIVERY-CHECKLIST.md` | Umfang einer Bereitstellung mit Freigabe | Ja, je Bereitstellung |

**Rangfolge**: Bestellformular → `COMMERCIAL-LICENSE.md` → `PRICING.md` →
übrige Dokumente. Die Apache-2.0-Lizenz wird durch kein Dokument dieser Liste
geändert.

**Sprache**: Alle rechtlichen Dokumente werden auf Englisch geschlossen.
Deutschsprachige Fassungen dienen der Lesbarkeit und sind nicht verbindlich.
