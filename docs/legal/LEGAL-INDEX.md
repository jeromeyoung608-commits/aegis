# Legal documents — index and order of precedence

| Document | Purpose | Binding? |
|---|---|---|
| `LICENSE` (Apache-2.0) | Licence for the software | Yes, for software use |
| `NOTICE` | Third-party components and their licences | Yes, mandatory attribution |
| `docs/legal/ORDER-FORM-TEMPLATE.md` | Commercial terms of one engagement | Yes, once signed |
| `COMMERCIAL-LICENSE.md` | Support and services terms | Yes, once referenced by an Order Form |
| `PRICING.md` | List prices and plan descriptions | No (informational) |
| `TRADEMARK.md` | Name and mark usage rules | Yes, as a statement of rights |
| `SECURITY.md` | Vulnerability disclosure policy | Policy, not a contract |
| `docs/legal/DPA-STATEMENT.md` | Data processing position and short DPA | Yes, when support access is granted |
| `docs/SERVICES-AGREEMENT.md` | Full services agreement behind the Order Form | Yes, once signed |
| `docs/DEPLOYMENT-DELIVERY-CHECKLIST.md` | Scope of a deployment, with sign-off | Yes, per deployment |

**Order of precedence**: Order Form → `COMMERCIAL-LICENSE.md` → `PRICING.md` → other documents. The Apache-2.0 licence is never modified by any document in this list.

**Language**: every legal document is concluded in English. German, French and
Spanish versions exist for readability and are non-binding translations.
