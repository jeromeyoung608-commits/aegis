# Languages

| Language | Documentation | Console UI | Legal documents |
|---|---|---|---|
| English | All documents (authoritative) | Yes | Binding version |
| German | Suffix `.de.md` | Yes | Translation, non-binding |
| French | Suffix `.fr.md` | Yes | Translation, non-binding |
| Spanish | Suffix `.es.md` | Yes | Translation, non-binding |

Code, comments, commands, identifiers and module interfaces are English only.
Every translation states that the English text prevails. `LICENSE` and `NOTICE`
are English only and are never translated.
